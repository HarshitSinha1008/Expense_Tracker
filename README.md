# 💰 Expense Tracker

A simple and elegant Expense Tracker web application that allows users to log daily expenses, visualize data using a pie chart, and manage their spending habits effectively. Built with **HTML**, **CSS**, and **JavaScript**.

---

## 🌟 Features

- Add daily expenses with item name, amount, and date
- Interactive Pie Chart using **Chart.js**
- Data stored in **LocalStorage**
- Clear all entries with a single click
- Responsive and minimal UI
